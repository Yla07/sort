# Sortowanie cyfr

## Web app

Start the Python backend and web frontend together with:

```bash
python server.py
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000). The web app uses the same sorting class as the CLI and desktop GUI, with endpoints for generating, editing, clearing, and sorting the current dataset.

## Other interfaces

- CLI: `python cli.py`
- Desktop GUI: `python gui.py`
